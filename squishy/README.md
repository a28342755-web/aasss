# 말랑말랑 찹쌀이

손가락으로 꾹 누르고 쭉 늘리는 3D 말랑이 사이트예요. 주인공은 머리에 새싹이 난 동글동글 찹쌀떡 **찹쌀이**예요.

## 만지는 법

| 동작 | 반응 |
| --- | --- |
| 꾹 누르기 | 누른 자리가 쏙 들어가고 몸 전체가 찌부돼요. 오래 누르면 "뀨!" 소리가 나요 |
| 누른 채로 당기기 | 떡처럼 쭉 늘어났다가 놓으면 출렁이며 돌아와요. 너무 세게 당기면 "뾱!" 하고 미끄러져요 |
| 두 손가락으로 잡기 | 양쪽을 동시에 누르거나 늘릴 수 있어요 |
| 톡톡 두 번 | 폴짝 점프해요 |
| 새싹 건드리기 | 새싹이 띠용 흔들려요 |
| 빈 곳 드래그 / 두 손가락 벌리기 | 빙글 돌려보고 확대·축소해요. 빈 곳을 두 번 톡톡 치면 처음 시점으로 돌아가요 |
| 짧은 시간에 많이 누르기 | 볼을 부풀리며 삐져요 |
| 30초 동안 가만히 두기 | 새근새근 잠들어요. 다시 만지면 깜짝 놀라 깨요 |

키보드로는 화면을 선택한 뒤 스페이스(누르기), 화살표(돌리기), J(점프)를 쓸 수 있어요.

- **맛 7가지**: 우유, 딸기, 말차, 망고, 소다, 타로, 초코
- **질감 3가지**: 말랑(천천히 부풀어 오름), 탱글(통통 튀고 출렁임), 쫀득(길게 늘어남)
- 만진 횟수, 고른 맛과 질감은 브라우저에 저장돼요.
- 소리는 파일 없이 Web Audio로 그때그때 만들어요. 휴대폰에서는 진동도 함께 울려요(지원하는 기기만).

## 실행

ES 모듈을 쓰기 때문에 `file://`로 바로 열면 동작하지 않아요. 이 폴더에서 아무 정적 서버나 띄우면 돼요.

```bash
cd squishy
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 열어요. three.js는 jsDelivr CDN(`three@0.170.0`)에서 불러오므로 인터넷 연결이 필요해요.

## 배포 (GitHub Pages)

저장소 **Settings → Pages**에서 브랜치를 `main`, 폴더를 `/ (root)`로 지정하면
`https://<사용자명>.github.io/<저장소명>/squishy/` 주소로 열려요.

## 구조

```
squishy/
├── index.html      화면 구성과 three.js import map
├── style.css       색 토큰(라이트/다크), 레이아웃, 효과 애니메이션
└── src/
    ├── main.js     장면, 카메라, 터치 입력, UI, 메인 루프
    ├── mochi.js    찹쌀이 몸체, 말랑 변형과 스프링 물리, 표정, 새싹
    ├── shaders.js  몸체 셰이더 (얼굴을 피부 위에 절차적으로 그림)
    ├── sound.js    Web Audio 효과음 합성
    └── fx.js       하트, 반짝이, Zzz, 토스트
```

몸체는 꼭짓점을 공유하는 아이코스피어(약 1만 개 꼭짓점)를 찹쌀떡 모양으로 빚은 것이에요. 손가락이 닿을 때마다 그 자리에 "변형점"이 생겨요. 변형점은 표면을 법선 방향으로 누르는 힘과 손가락을 따라 끄는 힘을 각각 스프링으로 움직이고, 질감 설정에 따라 스프링의 탄성과 감쇠가 달라져요. 얼굴은 텍스처가 아니라 변형 전 위치를 기준으로 셰이더에서 그려서, 몸이 늘어나면 표정도 같이 늘어나요.
