# Aster AI Android

Aster AI를 휴대폰 홈 화면에서 실행하는 설치형 안드로이드 앱입니다.

## 앱 기능

- 홈 화면 아이콘으로 실행
- 모바일 채팅 UI
- 답변 스트리밍 표시와 생성 중지
- 새 대화, 답변 복사, 코드 블록 표시
- 서버 연결 확인과 모델 선택
- 대화 및 설정 자동 저장
- 밝은 화면/어두운 화면 자동 적용

## 사용 조건

앱 자체에는 AI 모델이 포함되지 않습니다. 휴대폰과 같은 네트워크에 있는 Ollama 서버 또는 호환 프록시 주소가 필요합니다. 최초 실행 시 앱 설정에서 서버 주소와 모델 이름을 입력합니다.

최소 Android 8.0(API 26) 이상입니다.

## 미니 MMORPG (`mmorpg/`)

여러 명이 같은 월드에서 함께 사냥하는 브라우저 MMORPG입니다. Aster AI 앱과는 별개이며 Node.js만 있으면 됩니다(추가 설치 없음).

```
node mmorpg/server.js
```

PC에서는 `http://localhost:3000`, 같은 와이파이의 휴대폰에서는 `http://PC주소:3000` 으로 접속합니다.

- 땅을 누르면 이동, 몬스터를 누르면 다가가서 자동 공격
- 마을(가운데 원)에서 멀수록 몬스터 레벨이 높고 경험치가 많음
- 마을 안에서는 빠르게 회복, 쓰러지면 마을에서 부활
- 전체 채팅, 레벨·경험치 자동 저장(`mmorpg/saves.json`)
- 캐릭터 이름은 처음 만든 브라우저에 묶입니다(브라우저 데이터를 지우면 그 이름으로 다시 접속할 수 없음)
- 테스트: `node mmorpg/test.js`
