# Aster AI Android

Aster AI를 휴대폰 홈 화면에서 실행하는 설치형 안드로이드 앱입니다.

## 앱 기능

- 홈 화면 아이콘으로 실행
- 모바일 채팅 UI
- 답변 스트리밍 표시와 생성 중지
- 새 대화, 답변 복사, 코드 블록 표시
- 서버 연결 확인과 모델 선택
- 대화 및 설정 자동 저장
- 밝은 화면/어두운 화면 자동 적용

## 사용 조건

앱 자체에는 AI 모델이 포함되지 않습니다. 휴대폰과 같은 네트워크에 있는 Ollama 서버 또는 호환 프록시 주소가 필요합니다. 최초 실행 시 앱 설정에서 서버 주소와 모델 이름을 입력합니다.

최소 Android 8.0(API 26) 이상입니다.

## LBM 3D 풍동 (fluid-sim)

`fluid-sim/index.html`은 브라우저 GPU에서 돌아가는 정밀 3차원 유체역학 시뮬레이터입니다. D3Q19 격자 볼츠만법으로 구·원기둥·날개·차체 주위 유동을 풀고, 항력·양력 계수와 Strouhal 수를 문헌값과 비교합니다. 자세한 내용은 [fluid-sim/README.md](fluid-sim/README.md)를 보세요.
