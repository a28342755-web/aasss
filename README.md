# Aster AI Android

Aster AI를 휴대폰 홈 화면에서 실행하는 설치형 안드로이드 앱입니다.

## 앱 기능

- 홈 화면 아이콘으로 실행
- 모바일 채팅 UI
- 답변 스트리밍 표시와 생성 중지
- 새 대화, 답변 복사, 코드 블록 표시
- 서버 연결 확인과 모델 선택
- 대화 및 설정 자동 저장
- 밝은 화면/어두운 화면 자동 적용

## 사용 조건

앱 자체에는 AI 모델이 포함되지 않습니다. 휴대폰과 같은 네트워크에 있는 Ollama 서버 또는 호환 프록시 주소가 필요합니다. 최초 실행 시 앱 설정에서 서버 주소와 모델 이름을 입력합니다.

최소 Android 8.0(API 26) 이상입니다.

## 삼천의 운명 (웹 RPG)

`rpg/` 폴더에는 직업 3,000개 중 하나가 무작위로 정해지는 횡스크롤 도트 액션 RPG가 들어 있습니다. 마을에서 준비하고 지하 동굴을 한 층씩 내려가며 실시간으로 싸웁니다. `rpg/index.html`을 브라우저로 열면 바로 실행됩니다. 자세한 내용은 [rpg/README.md](rpg/README.md)를 보세요.
