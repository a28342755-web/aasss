# Aster AI Android

Aster AI를 휴대폰 홈 화면에서 실행하는 설치형 안드로이드 앱입니다.

## 앱 기능

- 홈 화면 아이콘으로 실행
- 모바일 채팅 UI
- 답변 스트리밍 표시와 생성 중지
- 새 대화, 답변 복사, 코드 블록 표시
- 서버 연결 확인과 모델 선택
- 대화 및 설정 자동 저장
- 밝은 화면/어두운 화면 자동 적용

## 사용 조건

앱 자체에는 AI 모델이 포함되지 않습니다. 휴대폰과 같은 네트워크에 있는 Ollama 서버 또는 호환 프록시 주소가 필요합니다. 최초 실행 시 앱 설정에서 서버 주소와 모델 이름을 입력합니다.

최소 Android 8.0(API 26) 이상입니다.

## Aster Synth (코드 패드 신디사이저)

`synth/` 모듈은 Aster AI와 따로 설치되는 별도 앱(`com.aster.synth`)입니다. 빌드하면 `AsterSynth.apk`가 함께 만들어집니다.

- 키와 스케일(메이저/마이너)을 고르면 그 조에 맞는 코드 패드 7개가 만들어집니다. 누르고 있는 동안 소리가 나며 여러 패드를 동시에 누를 수 있습니다.
- `7th`를 켜면 패드가 7화음으로 바뀝니다.
- `녹음`을 켜고 패드를 누르면 코드 진행이 쌓이고, `재생`으로 BPM에 맞춰 반복 재생합니다. 진행의 코드를 누르면 삭제됩니다.
- 파형, 필터, 어택, 릴리즈로 음색을 조절합니다.
- 설정과 코드 진행은 자동 저장되며, 네트워크 권한 없이 오프라인으로 동작합니다.
