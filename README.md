# Aster AI Android

Aster AI를 휴대폰 홈 화면에서 실행하는 설치형 안드로이드 앱입니다.

## 앱 기능

- 홈 화면 아이콘으로 실행
- 모바일 채팅 UI
- 답변 스트리밍 표시와 생성 중지
- 새 대화, 답변 복사, 코드 블록 표시
- 서버 연결 확인과 모델 선택
- 대화 및 설정 자동 저장
- 밝은 화면/어두운 화면 자동 적용

## 사용 조건

앱 자체에는 AI 모델이 포함되지 않습니다. 휴대폰과 같은 네트워크에 있는 Ollama 서버 또는 호환 프록시 주소가 필요합니다. 최초 실행 시 앱 설정에서 서버 주소와 모델 이름을 입력합니다.

최소 Android 8.0(API 26) 이상입니다.

## Ironhoof (ASCII 오픈월드 게임)

`ironhoof/index.html` 파일 하나로 동작하는 브라우저 게임입니다. 설치·빌드 없이 파일을 브라우저에서 열면 됩니다(WebGL2 필요).
철갑 기사와 마갑을 두른 군마로 절차적으로 생성되는 무한 세계(평원·숲·설산·사막·늪·강·해안·마을·도시·폐성·지하 유적)를 탐험합니다.

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 도보 이동 / 승마 시 조향 |
| Shift, X | 도보 달리기 · 승마 보법 올리기 / 보법 내리기 (평보·속보·구보·습보) |
| F, H | 승하차 / 휘파람으로 군마 호출 |
| Space·클릭, E | 공격 / 대화·상자·계단 |
| R, M | 야영 휴식 / 지도 |
| 드래그, 휠, Z·C | 시점 회전·기울기 / 줌 / 시점 회전 |
| P, L, Esc | 저장 / 불러오기 / 메뉴 (자동 저장됨) |

터치 화면에서는 화면 왼쪽을 끌어 이동하고, 하단의 ASCII 버튼을 누릅니다. 자체 점검은 `ironhoof/index.html#selftest`로 열면 탭 제목에 PASS/FAIL이 표시됩니다.
