# Aster AI Android

Aster AI를 휴대폰 홈 화면에서 실행하는 설치형 안드로이드 앱입니다.

## 앱 기능

- 홈 화면 아이콘으로 실행
- 모바일 채팅 UI
- 답변 스트리밍 표시와 생성 중지
- 새 대화, 답변 복사, 코드 블록 표시
- 서버 연결 확인과 모델 선택
- 대화 및 설정 자동 저장
- 밝은 화면/어두운 화면 자동 적용

## 사용 조건

앱 자체에는 AI 모델이 포함되지 않습니다. 휴대폰과 같은 네트워크에 있는 Ollama 서버 또는 호환 프록시 주소가 필요합니다. 최초 실행 시 앱 설정에서 서버 주소와 모델 이름을 입력합니다.

최소 Android 8.0(API 26) 이상입니다.

## 낚시 게임: 찌올림 (`fishing-game/`)

늦가을 산골 저수지에서 하는 1인칭 3D 릴찌낚시 게임입니다. `fishing-game/index.html`을 브라우저로 열면 바로 실행됩니다(three.js를 CDN에서 받으므로 인터넷 연결 필요).

- 11월 초 실제 해 위치(일출 7:08·일몰 17:24), 능선 그늘, 새벽 물안개, 기온·수온·바람
- 찌맞춤한 장찌와 어종별 입질: 붕어는 찌가 솟고(찌올림), 배스는 쑥 빨고, 잉어는 끌고 들어간다
- 원줄 신장 + 낚싯대 휨 + 드랙 미끄러짐으로 계산한 장력. 목줄 강도를 넘으면 터지고, 줄이 늘어지면 바늘이 빠진다
- 붕어·잉어·향어·배스·블루길·메기·동자개·강준치의 실제 전장-무게 관계식, 계측자 실측, 월척·런커 기록
- 물리 점검: `node fishing-game/sim.test.mjs`
