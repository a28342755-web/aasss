# 삼천의 운명

직업 3,000개 가운데 하나가 무작위로 정해지는 2D 도트 RPG입니다. 마을과 던전을 직접 걸어 다니고, 몬스터와 부딪히면 턴제 전투가 벌어집니다. 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | 방향키 · WASD | 화면 아래 십자 패드 |
| 결정 · 조사 · 대화 | Z · Enter · Space | A |
| 메뉴 · 취소 | X · Esc | B |

전투 연출 중에 결정 키를 누르면 빨리 감기가 됩니다.

## 게임 방법

1. **운명 뽑기**: 운명의 석판이 3,000개 직업 중 하나를 무작위로 고릅니다. 마음에 들지 않으면 3번까지 다시 굴릴 수 있습니다.
2. **마을**: 여관(HP·MP 회복), 상점(물약, 무기·방어구 강화, 전직의 두루마리), 모험가 길드(직업 도감, 명예의 전당), 운명의 석판, 주민들이 있습니다. 동굴 입구로 들어가면 던전입니다.
3. **던전**: 층마다 방과 통로가 새로 만들어집니다. 몬스터는 다가오는 주인공을 쫓아오고, 닿으면 전투가 시작됩니다. 상자에는 물약과 골드가 들어 있고, 계단을 밟으면 다음 층으로 내려갑니다. 10층마다 보스방이 있고, 보스를 쓰러뜨려야 계단이 열립니다. 메뉴에서 언제든 마을로 돌아갈 수 있습니다.
4. **전투**: 기본 공격, 기술 5개, 방어, 물약, 도망 중에서 고릅니다. 기술마다 속성이 있어 적의 약점을 찌르면 피해가 1.5배입니다. 궁극기(Lv.10)는 마법진과 함께 화면 전체를 뒤덮습니다.
5. **죽음**: 쓰러지면 명예의 전당에 기록되고 새 운명을 뽑습니다. 10층을 넘길 때마다 다음 운명의 재굴림 기회가 1번씩 늘어납니다.

**전직의 두루마리**를 사면 레벨·장비·골드는 그대로 두고 직업만 다시 무작위로 정해집니다. 만난 직업은 **직업 도감**에 기록됩니다.

## 그래픽

- **캐릭터**: 3,000개 직업 모두 겉모습이 다릅니다. 계열별 옷 형태(갑옷, 로브, 도복, 앞치마…), 직업 이름에 맞는 무기와 모자(대장장이의 망치, 요리사의 조리모, 사무라이의 카타나…), 종족 특징(엘프 귀, 오크 엄니, 천사 고리, 유령의 투명한 몸…), 속성 오라와 등급 색을 조합해 코드로 그립니다. 4방향 걷기, 대기, 점프, 공격, 시전, 피격, 승리 동작이 있고 같은 광원으로 음영을 넣습니다.
- **몬스터**: 61종. 도트 원본을 Scale2x/Scale3x로 키운 다음 실루엣에서 입체 음영과 색 외곽선을 자동으로 입힙니다.
- **효과**: 화염구, 얼음 가시, 낙뢰, 성광 기둥, 운석 낙하, 블랙홀 등 속성·기술 유형별 파티클 연출.
- **계열 초상화**: 운명 뽑기 화면과 도감의 36개 계열 초상화(`assets/portraits/`)는 AI 이미지 생성으로 만들었습니다.
- **글꼴**: [갈무리11](https://github.com/quiple/galmuri) (SIL Open Font License 1.1, `assets/fonts/Galmuri-LICENSE.txt`). 한글·영문만 남기도록 줄인 파일입니다.

## 직업 구성

| 구분 | 내용 |
| --- | --- |
| 계열 | 36개: 전투 24개, 생활(비전투) 12개 |
| 기본 직업 | 731개, 모두 직접 작성한 이름·설명·대표 기술 |
| 수식어(기원) | 108개: 속성(화염, 심연…), 지역(북방, 사막…), 종족(엘프, 드워프…), 신분·성향(왕실, 타락한…), 신화급(용혈, 공허…) |
| 전체 직업 | 정확히 3,000개 = 기본 직업 731 + "수식어 + 기본 직업" 변종 2,269 |
| 등급 | 일반 1,200 · 고급 840 · 희귀 510 · 영웅 270 · 전설 135 · 신화 45 |

전투 계열: 전사, 기사, 궁수, 화약, 도적, 암살, 원소 마법, 비전 마법, 흑마법, 성직, 자연, 주술, 무도, 소환, 음악, 공학, 연금, 동방 무협, 사냥, 해양, 군사, 천체, 기예, 이형 혈통

생활 계열: 농업·목축, 채집·어업·광업, 제작·장인, 요리·식음, 상업·경제, 학문·지식, 예술·공연, 의료·돌봄, 행정·치안, 생활·서비스, 건축·토목, 신앙·신비

예: 광전사, 성기사, 흑기사, 검성, 북방 광전사, 타락한 성기사, 엘프 양봉가, 용혈 농부, 공허 제빵사, 드워프 대장장이, 유령 등대지기

생활 계열은 공격력이 낮은 대신 계열 특성이 강합니다. 농부는 전투 후 HP를 회복하고, 상인은 골드를 60% 더 벌고, 장인은 상점 물건을 싸게 사고, 학자는 경험치를 더 얻고 적의 약점을 꿰뚫어 봅니다.

각 직업은 기본 공격과 기술 5개를 가집니다: 계열 기술 2개, 대표 기술, 기원 기술(정통 직업은 대표 기술의 각성판), 궁극기(Lv.10).

```
rpg/

├── assets/
│   ├── fonts/            갈무리11 (한글·영문 축소본)과 라이선스
│   └── portraits/        계열 초상화 36장 (webp)
├── js/data-jobs.js       36개 계열과 기본 직업 731개
├── js/data-world.js      속성, 등급, 기술 유형, 수식어, 몬스터
├── js/jobs.js            직업 3,000개 생성기 (고정 시드라 매번 같은 결과)
├── js/engine.js          전투·성장·상점 로직 (DOM 없이 동작)
├── js/sprites.js         팔레트, 몬스터·타일·아이콘 도트, 직업별 외형 규칙
├── js/doll.js            직업 캐릭터 고해상도 도트 렌더러 (동작별 포즈)
├── js/world.js           마을 지도, 던전 생성기, 지형·건물·소품 그림
├── js/effects.js         파티클과 기술 연출, 데미지 숫자
├── js/game.js            게임 루프, 장면(타이틀·운명 뽑기·필드·전투), 입력, 창, 저장
└── tools/
    ├── verify-jobs.js    직업 수·이름 중복·데이터 값 검증

```

## 직업·밸런스 수정

- 기본 직업 추가: `js/data-jobs.js`의 해당 계열 `jobs`에 `이름|설명|대표 기술|기술 유형|주 능력치|등급|속성` 한 줄을 넣습니다. 총합은 생성기가 자동으로 3,000개에 맞춥니다.
- 수식어 추가: `js/data-world.js`의 `MODIFIERS`에 한 줄을 넣습니다.
- 겉모습 규칙: 직업 이름 → 무기·모자는 `js/sprites.js`의 `WEAPON_RULES`, `HAT_RULES`, 계열별 옷 형태는 `js/doll.js`의 `OUTFIT_TYPE`입니다.
- 수정 후 검증:

```bash
node rpg/tools/verify-jobs.js --sample        # 3,000개·중복 없음 확인, 표본 출력
node rpg/tools/simulate.js 1000 --families    # 계열·등급별 도달 층수 비교
```

진행 상황(캐릭터, 도감, 명예의 전당)은 브라우저 `localStorage`에 저장됩니다.
