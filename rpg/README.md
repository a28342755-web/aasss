# 삼천의 운명

직업 3,000개 가운데 하나가 무작위로 정해지는 횡스크롤 도트 액션 RPG입니다. 마을에서 준비하고 동굴로 내려가 지하 층을 하나씩 뚫고 내려갑니다. 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | ← → | 십자 패드 |
| 밧줄·사다리 오르내리기, 문 들어가기 | ↑ ↓ | 십자 패드 |
| 발판 아래로 내려가기 | ↓ + Space | ↓ + 점프 |
| 점프 | Space · C | 점프 |
| 기본 공격 | Z · Ctrl | 공격 |
| 기술 1~5 (5번은 궁극기) | A S D F G | 위쪽 기술 칸 |
| HP·MP 물약 | Q · W | HP · MP |
| 대화·결정 | Enter | 공격 · 점프 |
| 메뉴·취소 | Esc · X | B |

## 게임 방법

1. **운명 뽑기**: 운명의 석판이 3,000개 직업 중 하나를 무작위로 고릅니다. 뽑힌 캐릭터가 대기·걷기·점프·착지·기본 공격·기술·궁극기를 차례로 보여 줍니다. 마음에 들지 않으면 3번까지 다시 굴릴 수 있습니다.
2. **마을**: 여관(HP·MP 회복), 상점(물약, 무기·방어구 강화, 전직의 두루마리), 모험가 길드(직업 도감, 명예의 전당), 운명의 석판이 있습니다. 오른쪽 끝 동굴 입구로 들어가면 지하 1층입니다.
3. **지하 층**: 동굴 테마 5가지(흙동굴, 이끼 석굴, 지하 묘지, 얼음 동굴, 심연)가 10층마다 바뀌고, 층마다 새 지형이 만들어집니다. 발판, 밧줄, 사다리를 타고 다니며 몬스터를 쓰러뜨리고, 오른쪽 끝 아래층 문으로 내려갑니다. 10층마다 보스가 있고, 보스를 쓰러뜨려야 문이 열립니다. 메뉴에서 언제든 마을로 돌아갈 수 있습니다.
4. **전투**: 몬스터에 닿으면 피해를 입습니다. 기본 공격과 기술 5개는 모두 실시간이고 기술마다 재사용 대기 시간이 있습니다. 기술마다 속성이 있어 적의 약점을 찌르면 피해가 1.5배입니다. 궁극기(Lv.10)는 마법진과 떠오르는 결정 → 직업에 맞는 대폭격 → 빛기둥 순서로 화면 안의 모든 적을 세 번 내리칩니다.
5. **죽음**: 쓰러지면 명예의 전당에 기록되고 새 운명을 뽑습니다. 10층을 넘길 때마다 다음 운명의 재굴림 기회가 1번씩 늘어납니다.

**전직의 두루마리**를 사면 레벨·장비·골드는 그대로 두고 직업만 다시 무작위로 정해집니다. 만난 직업은 **직업 도감**에 기록됩니다.

## 그래픽

- **캐릭터**: 2~3등신 캐릭터 그림 90가지(`assets/heroes/`)를 AI 이미지 생성으로 만들었습니다. 계열마다 1~5가지가 있고, 직업 이름의 낱말로 가장 어울리는 그림을 고릅니다(광전사 → 도끼 전사, 화염술사 → 불꽃 마법사, 요리사 → 요리사). 대기(숨쉬기), 걷기, 점프, 낙하, 착지, 공격(뒤로 젖혔다 내지르기), 시전, 피격, 매달리기 동작은 그림을 기울이고 늘이고 눌러서 만듭니다.
- **싸우는 방식**: 그림마다 싸움 방식이 정해져 있습니다. 검사·기사·무도가는 베기, 궁수와 사냥꾼은 화살과 화살비, 총잡이와 공학자는 총탄과 포격, 음유시인·광대·상인은 음표·카드·동전 던지기, 마법 계열은 속성 주문(화염구, 얼음 결정, 낙뢰, 회오리, 빛기둥)을 씁니다.
- **몬스터**: 61종. 도트 원본을 Scale2x/Scale3x로 키운 다음 실루엣에서 입체 음영과 색 외곽선을 자동으로 입힙니다.
- **배경**: 동굴 바위, 기둥, 수정, 횃불, 밧줄과 사다리, 마을 건물을 코드로 그립니다.
- **계열 초상화**: 운명 뽑기 화면과 도감의 36개 계열 초상화(`assets/portraits/`)는 AI 이미지 생성으로 만들었습니다.
- **글꼴**: [갈무리11](https://github.com/quiple/galmuri) (SIL Open Font License 1.1, `assets/fonts/Galmuri-LICENSE.txt`). 한글·영문만 남기도록 줄인 파일입니다.

## 직업 구성

| 구분 | 내용 |
| --- | --- |
| 계열 | 36개: 전투 24개, 생활(비전투) 12개 |
| 기본 직업 | 731개, 모두 직접 작성한 이름·설명·대표 기술 |
| 수식어(기원) | 108개: 속성(화염, 심연…), 지역(북방, 사막…), 종족(엘프, 드워프…), 신분·성향(왕실, 타락한…), 신화급(용혈, 공허…) |
| 전체 직업 | 정확히 3,000개 = 기본 직업 731 + "수식어 + 기본 직업" 변종 2,269 |
| 등급 | 일반 1,200 · 고급 840 · 희귀 510 · 영웅 270 · 전설 135 · 신화 45 |

전투 계열: 전사, 기사, 궁수, 화약, 도적, 암살, 원소 마법, 비전 마법, 흑마법, 성직, 자연, 주술, 무도, 소환, 음악, 공학, 연금, 동방 무협, 사냥, 해양, 군사, 천체, 기예, 이형 혈통

생활 계열: 농업·목축, 채집·어업·광업, 제작·장인, 요리·식음, 상업·경제, 학문·지식, 예술·공연, 의료·돌봄, 행정·치안, 생활·서비스, 건축·토목, 신앙·신비

예: 광전사, 성기사, 흑기사, 검성, 북방 광전사, 타락한 성기사, 엘프 양봉가, 용혈 농부, 공허 제빵사, 드워프 대장장이, 유령 등대지기

생활 계열은 공격력이 낮은 대신 계열 특성이 강합니다. 농부는 몇 초마다 HP를 회복하고, 상인은 골드를 60% 더 벌고, 장인은 상점 물건을 싸게 사고, 학자는 경험치를 더 얻고 적의 약점을 꿰뚫어 봅니다.

각 직업은 기본 공격과 기술 5개를 가집니다: 계열 기술 2개, 대표 기술, 기원 기술(정통 직업은 대표 기술의 각성판), 궁극기(Lv.10).

```
rpg/
├── index.html            화면 틀 (캔버스, 창, 터치 패드)

├── assets/
│   ├── fonts/            갈무리11 (한글·영문 축소본)과 라이선스
│   ├── heroes/           캐릭터 그림 90장 (webp)
│   └── portraits/        계열 초상화 36장 (webp)
├── js/data-jobs.js       36개 계열과 기본 직업 731개
├── js/data-world.js      속성, 등급, 기술 유형, 수식어, 몬스터
├── js/jobs.js            직업 3,000개 생성기 (고정 시드라 매번 같은 결과)

├── js/sprites.js         팔레트, 몬스터·아이콘 도트
├── js/doll.js            코드로 그리는 도트 인형 (마을 주민, 그림을 못 읽었을 때 대신)
├── js/world.js           마을과 지하 층 지형 생성기, 배경·발판·소품 그림
├── js/effects.js         도트 파티클
├── js/spells.js          기술 연출(화염구, 결정, 낙뢰, 마법진, 운석, 빛기둥…)과 데미지 숫자
├── js/heroes.js          직업 → 캐릭터 그림·싸움 방식 고르기
├── js/heroart.js         캐릭터 그림 불러오기와 동작
├── js/game.js            게임 루프, 장면(타이틀·운명 뽑기·마을·지하 층), 입력, 창, 저장
└── tools/
    ├── verify-jobs.js    직업 수·이름 중복·데이터 값 검증

```

## 직업·밸런스 수정

- 기본 직업 추가: `js/data-jobs.js`의 해당 계열 `jobs`에 `이름|설명|대표 기술|기술 유형|주 능력치|등급|속성` 한 줄을 넣습니다. 총합은 생성기가 자동으로 3,000개에 맞춥니다.
- 수식어 추가: `js/data-world.js`의 `MODIFIERS`에 한 줄을 넣습니다.
- 캐릭터 그림 고르기: `js/heroes.js`의 `ART`에 `[그림 id, 계열 id, 직업 이름 낱말]`을 넣고 `assets/heroes/<그림 id>.webp`를 추가합니다. 싸움 방식은 같은 파일의 `STYLE_BY_PREFIX`, `STYLE_BY_ID`입니다.
- 몬스터 세기: `js/engine.js`의 `makeMonster`입니다.
- 수정 후 검증:

```bash
node rpg/tools/verify-jobs.js --sample        # 3,000개·중복 없음 확인, 표본 출력
node rpg/tools/autoplay.js 6 30               # 무작위 직업 6명으로 30층까지, 5층마다 최저 HP·물약 수
```

진행 상황(캐릭터, 도감, 명예의 전당)은 브라우저 `localStorage`에 저장됩니다.
