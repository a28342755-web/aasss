# 삼천의 운명

직업 3,000개 가운데 하나가 무작위로 정해지는 횡스크롤 도트 액션 RPG입니다. 마을에서 준비하고 동굴로 내려가 지하 층을 하나씩 뚫고 내려갑니다. 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | ← → | 십자 패드 |
| 달리기 | 방향키를 계속 누르기 · Shift | 방향을 계속 누르기 |
| 밧줄·사다리 오르내리기, 문 들어가기 | ↑ ↓ | 십자 패드 |
| 발판 아래로 내려가기 | ↓ + Space | ↓ + 점프 |
| 점프 | Space · C | 점프 |
| 기본 공격 | Z · Ctrl | 공격 |
| 기술 1~5 (5번은 궁극기) | A S D F G | 위쪽 기술 칸 |
| HP·MP 물약 | Q · W | HP · MP |
| 대화·결정 | Enter | 공격 · 점프 |
| 메뉴·취소 | Esc · X | B |

## 게임 방법

1. **운명 뽑기**: 운명의 석판이 3,000개 직업 중 하나를 무작위로 고릅니다. 뽑힌 캐릭터가 대기·걷기·점프·착지·기본 공격·기술·궁극기를 차례로 보여 줍니다. 마음에 들지 않으면 3번까지 다시 굴릴 수 있습니다.
2. **마을**: 여관(HP·MP 회복), 상점(물약, 무기·방어구 강화, 전직의 두루마리), 모험가 길드(직업 도감, 명예의 전당), 운명의 석판이 있습니다. 오른쪽 끝 동굴 입구로 들어가면 지하 1층입니다.
3. **지하 층**: 동굴 테마 5가지(흙동굴, 이끼 석굴, 지하 묘지, 얼음 동굴, 심연)가 10층마다 바뀌고, 층마다 새 지형이 만들어집니다. 발판, 밧줄, 사다리를 타고 다니며 몬스터를 쓰러뜨리고, 오른쪽 끝 아래층 문으로 내려갑니다. 10층마다 보스가 있고, 보스를 쓰러뜨려야 문이 열립니다. 메뉴에서 언제든 마을로 돌아갈 수 있습니다.
4. **전투**: 몬스터에 닿으면 피해를 입습니다. 기본 공격과 기술 5개는 모두 실시간이고 기술마다 재사용 대기 시간이 있습니다. 기술마다 속성이 있어 적의 약점을 찌르면 피해가 1.5배입니다. 궁극기(Lv.10)는 마법진과 떠오르는 결정 → 직업에 맞는 대폭격 → 빛기둥 순서로 화면 안의 모든 적을 세 번 내리칩니다.
5. **죽음**: 쓰러지면 명예의 전당에 기록되고 새 운명을 뽑습니다. 10층을 넘길 때마다 다음 운명의 재굴림 기회가 1번씩 늘어납니다.

**전직의 두루마리**를 사면 레벨·장비·골드는 그대로 두고 직업만 다시 무작위로 정해집니다. 만난 직업은 **직업 도감**에 기록됩니다.

## 그래픽

- **캐릭터**: 2~3등신 캐릭터 그림 90가지(`assets/heroes/`)를 AI 이미지 생성으로 만들었습니다. 직업 이름의 낱말로 가장 어울리는 그림을 고릅니다(광전사 → 도끼 전사, 화염술사 → 불꽃 마법사, 요리사 → 요리사). 생활 계열은 이름이 더 잘 맞는 다른 계열 그림도 빌려 씁니다(나무꾼 → 도끼 전사, 간호사 → 치유 수녀, 철거공 → 폭탄병, 고고학자 → 도굴꾼). 대기(숨쉬기), 걷기, 점프, 낙하, 착지, 공격(뒤로 젖혔다 내지르기), 시전, 피격, 매달리기 동작은 그림을 기울이고 늘이고 눌러서 만듭니다.
- **머리 바꿔 달기**: 그림 82장에서 머리(얼굴·머리카락·모자·투구)를 떼어 다른 그림의 몸에 붙여 새 인물을 만듭니다. 얼굴 위치와 턱은 그림마다 직접 재 두었고(`js/heroes.js`의 `HEAD_AT`), 무기 자루처럼 머리에 닿은 가는 것은 떼어 내지 않습니다. 몸에 남는 긴 머리카락은 새 머리의 머리카락 색으로 칠합니다. 여성형 몸에는 여성형·중성 머리, 남성형 몸에는 남성형·중성 머리만 붙이고, 복면·투구는 전투 직업에만 씁니다. 수인은 늑대·여우 머리, 용인·리자드맨은 용 머리를 답니다.
- **같은 그림이라도 직업마다 다르게**: 직업마다 옷 색, 머리카락 색, 키를 다르게 칠합니다. 수식어가 붙은 직업은 그 수식어의 모습을 더합니다.
  - 종족: 엘프·고블린의 뾰족한 귀, 수인·고양이족의 동물 귀, 오크(초록 피부와 엄니), 트롤, 리자드맨, 언데드, 다크엘프의 피부색, 드워프·하플링·거인족의 체형
  - 혈통·신화급: 천사혈통·천상의 날개와 머리 고리, 악마혈통·마왕의 뿔과 박쥐 날개, 용혈의 용 날개와 뿔, 불사조의 불꽃 날개, 요정의 날개, 유령의 반투명한 몸
  - 그 밖: 쌍둥이의 분신, 그림자의 검은 잔상, 왕실·궁정·거장의 왕관, 속성(화염, 서리, 번개…)과 신화급 수식어(공허, 시공, 성좌…)의 기운
  - 등급: 영웅 이상은 등급 색으로 몸 둘레가 빛납니다.
- **움직임**: 걷다가 방향키를 계속 누르면(또는 Shift) 달리고, 점프는 조금 오래 떠 있습니다. 동작마다 뚜렷하게 다른 자세 프레임을 만들어 끊어서 번갈아 보여 줍니다. 그림에서 두 다리를 찾아 번갈아 내딛게 하고, 그 위에서 몸을 가로 띠로 나눠 기울이고 늘이고 눌러 자세를 잡습니다. 대기 4장(숨쉬기), 걷기 6장(다리 교차·몸 들썩임), 달리기 6장(앞으로 숙이고 머리카락·망토가 뒤로 날림), 점프(늘어남), 낙하, 착지(눌림), 무기별 공격 3장(준비 → 내지르기와 잔상 → 마무리), 시전, 피격이 있습니다. 긴 치마·로브는 옷단이 흔들립니다.
- **무기**: 직업마다 무기가 19가지 중 하나로 정해지고(그림과 직업 이름의 낱말로), 무기마다 동작·사거리·속도·피해가 다릅니다. 검(베기), 창(멀리 찌르며 둘을 꿰뚫음), 둔기(느리지만 내려찍어 셋을 함께, 땅이 울림), 쌍검(두 번), 주먹(짧고 빠름), 채찍(멀리 휘어 감음), 낫(앞뒤를 휩쓸음), 단검(빠르고 치명타), 활·석궁·총·포(포탄은 터지며 둘레까지), 지팡이(마력탄), 마도서(대상 자리에 룬이 터짐), 수정구(곧은 광선), 부적, 악기(음표), 소환수(혼령), 던지기(물약·카드·동전…).
- **기술 연출**: 기술 종류마다 다릅니다. 관통은 긴 찌르기나 광선, 연타는 무기 공격 세 번, 강타·기절은 내려찍기와 충격파, 화상·중독·저주·출혈은 불길·독 거품·보랏빛 연기·핏방울, 빙결은 얼음 분출, 흡수·마나는 대상에서 흘러 들어오는 빛, 혼란은 하트, 약화는 떨어지는 화살표, 강탈은 동전, 도박은 주사위, 급소·처형은 X자 베기입니다.
- **기술 그림**: 마력탄, 화염구, 얼음 분출, 번개, 운석, 운석 폭격, 룬 결정은 참고 시트(마법사의 밤)에서 오려 낸 그림(`assets/fx/`)을 속성 색으로 물들여 씁니다. 마법 궁극기는 마법진과 룬 결정 → 운석 폭격 → 빛기둥 순서입니다.
- **몬스터**: 61종. 도트 원본을 Scale2x/Scale3x로 키운 다음 실루엣에서 입체 음영과 색 외곽선을 자동으로 입힙니다.
- **배경**: 동굴 바위, 기둥, 수정, 횃불, 밧줄과 사다리, 마을 건물을 코드로 그립니다.
- **계열 초상화**: 운명 뽑기 화면과 도감의 36개 계열 초상화(`assets/portraits/`)는 AI 이미지 생성으로 만들었습니다.
- **글꼴**: [갈무리11](https://github.com/quiple/galmuri) (SIL Open Font License 1.1, `assets/fonts/Galmuri-LICENSE.txt`). 한글·영문만 남기도록 줄인 파일입니다.

생활 계열: 농업·목축, 채집·어업·광업, 제작·장인, 요리·식음, 상업·경제, 학문·지식, 예술·공연, 의료·돌봄, 행정·치안, 생활·서비스, 건축·토목, 신앙·신비

예: 광전사, 성기사, 흑기사, 검성, 북방 광전사, 타락한 성기사, 엘프 양봉가, 용혈 농부, 공허 제빵사, 드워프 대장장이, 유령 등대지기

생활 계열은 공격력이 낮은 대신 계열 특성이 강합니다. 농부는 몇 초마다 HP를 회복하고, 상인은 골드를 60% 더 벌고, 장인은 상점 물건을 싸게 사고, 학자는 경험치를 더 얻고 적의 약점을 꿰뚫어 봅니다.

각 직업은 기본 공격과 기술 5개를 가집니다: 계열 기술 2개, 대표 기술, 기원 기술(정통 직업은 대표 기술의 각성판), 궁극기(Lv.10).

## 직업·밸런스 수정

- 기본 직업 추가: `js/data-jobs.js`의 해당 계열 `jobs`에 `이름|설명|대표 기술|기술 유형|주 능력치|등급|속성` 한 줄을 넣습니다. 총합은 생성기가 자동으로 3,000개에 맞춥니다.
- 수식어 추가: `js/data-world.js`의 `MODIFIERS`에 한 줄을 넣습니다.
- 캐릭터 그림 고르기: `js/heroes.js`의 `ART`에 `[그림 id, 계열 id, 직업 이름 낱말]`을 넣고 `assets/heroes/<그림 id>.webp`를 추가한 뒤 `python3 rpg/tools/pack-heroes.py`를 실행합니다. 생활 직업에 빌려 줄 그림은 `LEND`, 싸움 방식은 `STYLE_BY_PREFIX`·`STYLE_BY_ID`, 무기는 `WEAPONS`·`WEAPON_BY_ART`·`WEAPON_WORDS`, 수식어별 겉모습은 `MOD_LOOK`입니다. 새 그림의 머리를 바꿔 달려면 `HEAD_AT`에 얼굴 가운데 x, 턱 y, 얼굴 폭을 넣고 `HEAD_TAG`·`BODY_TAKES`에 종류를 적습니다.
- 몬스터 세기: `js/engine.js`의 `makeMonster`입니다.
- 수정 후 검증:

```bash
node rpg/tools/verify-jobs.js --sample        # 3,000개·중복 없음 확인, 표본 출력
node rpg/tools/autoplay.js 6 30               # 무작위 직업 6명으로 30층까지, 5층마다 최저 HP·물약 수
```

진행 상황(캐릭터, 도감, 명예의 전당)은 브라우저 `localStorage`에 저장됩니다.
