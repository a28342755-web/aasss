# 삼천의 운명

직업 3,000개 가운데 하나가 무작위로 정해지는 턴제 도트 RPG입니다. 마을에서 준비하고 밤의 숲으로 내려가 포켓몬처럼 몬스터와 1대1로 번갈아 싸우며 층을 하나씩 뚫고 나아갑니다. 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 조작

모든 조작은 창(메뉴)에서 고르는 방식입니다.

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 고르기 | 방향키 | 십자 패드 |
| 결정 · 전투 연출 빨리 넘기기 | Z · Enter · Space | A |
| 취소 · 명령으로 돌아가기 | X · Esc | B |

전투 화면에서는 아래쪽의 큰 버튼을 바로 누르면 되므로 터치 패드를 숨깁니다. 화면을 누르면 글자와 연출이 빨리 넘어갑니다.

## 게임 방법

1. **운명 뽑기**: 운명의 석판이 3,000개 직업 중 하나를 무작위로 고릅니다. 뽑힌 캐릭터가 기본 공격·기술·궁극기를 차례로 보여 줍니다. 마음에 들지 않으면 3번까지 다시 굴릴 수 있습니다.
2. **마을**: 마을 메뉴에서 갈 곳을 고르면 화면이 그곳으로 옮겨 가고 주인공이 그 앞에 섭니다. 던전, 상점(물약, 무기·방어구 강화, 전직의 두루마리), 여관(HP·MP 회복), 모험가 길드(직업 도감, 명예의 전당, 조작 안내), 운명의 석판, 주민과 이야기, 메뉴(상태·도구·저장)가 있습니다.
3. **층**: 한 층마다 몬스터 셋과 차례로 싸웁니다. 10층마다 그 뒤에 보스가 하나 더 기다립니다. 층을 다 돌면 다음 층으로 내려가거나, 도구를 쓰거나, 마을로 돌아갈 수 있습니다(다음엔 그 층부터). 밤의 지역 5가지(별빛 숲, 달빛 언덕, 폐성 외곽, 서리 고원, 심연의 밤)가 10층마다 바뀝니다. 싸움 사이에는 HP·MP가 회복되지 않습니다.
4. **전투**: 포켓몬 4세대(DS) 방식입니다. 위 화면에는 멀리 오른쪽 위 받침에 몬스터, 가까이 왼쪽 아래에 주인공이 서고, 몬스터 이름표(이름·Lv·HP 바·상태)와 주인공 이름표(HP 바와 숫자·MP·EXP 바)가 서로를 가리킵니다. 그 아래 흰 대화창에 "앗! 야생의 슬라임이 튀어나왔다!", "시아의 강타!", "효과가 굉장했다!", "급소에 맞았다!" 같은 문장이 한 글자씩 찍히고, HP 바는 맞을 때마다 줄어들며 초록 → 노랑 → 빨강으로 바뀝니다. 아래 화면에는 커다란 **싸운다** 버튼과 **가방 · 도망 · 방어 · 상태** 버튼이 있고, 싸운다를 누르면 기본 공격과 기술 5개가 속성 색 카드(속성 이름표, PP 자리에 MP 소모·재사용 턴·배우는 레벨)로 나옵니다. 카드에 커서를 올리면 대화창에 기술 설명이 나옵니다. 주인공 → 몬스터 순서로 한 번씩 움직이고, 기술마다 속성이 있어 약점을 찌르면 피해가 1.5배입니다. 화상·중독·출혈·저주, 기절·빙결, 혼란, 약화 같은 상태와 공격력 강화, 재생, 보호막, 반격, 소환수가 턴 단위로 이어집니다. 몬스터는 특성에 따라 힘껏 내려찍거나, 두 번 공격하거나, 독·화상을 입히거나, 생명력을 빨거나, 골드를 훔칩니다. 몬스터를 쓰러뜨리면 받침 아래로 가라앉고, 경험치 바가 차오르며 레벨이 오릅니다. 가로로 든 휴대폰처럼 낮고 넓은 화면에서는 버튼 판이 오른쪽에 섭니다.
5. **죽음**: 쓰러지면 명예의 전당에 기록되고 새 운명을 뽑습니다. 10층을 넘길 때마다 다음 운명의 재굴림 기회가 1번씩 늘어납니다. 던전에서 저장하고 나가면 이어하기로 그 층의 그 싸움부터 다시 합니다.

**전직의 두루마리**를 사면 레벨·장비·골드는 그대로 두고 직업만 다시 무작위로 정해집니다. 만난 직업은 **직업 도감**에 기록됩니다.

## 그래픽

- **캐릭터**: 2~3등신 캐릭터 그림 90가지(`assets/heroes/`)를 AI 이미지 생성으로 만들었습니다. 직업 이름의 낱말로 가장 어울리는 그림을 고릅니다(광전사 → 도끼 전사, 화염술사 → 불꽃 마법사, 요리사 → 요리사). 생활 계열은 이름이 더 잘 맞는 다른 계열 그림도 빌려 씁니다(나무꾼 → 도끼 전사, 간호사 → 치유 수녀, 철거공 → 폭탄병, 고고학자 → 도굴꾼). 대기(숨쉬기), 공격(뒤로 젖혔다 내지르기), 시전, 피격, 승리 동작은 그림을 부위별로 나눠 기울이고 늘이고 눌러서 만듭니다.
- **머리 바꿔 달기**: 그림 82장에서 머리(얼굴·머리카락·모자·투구)를 떼어 다른 그림의 몸에 붙여 새 인물을 만듭니다. 얼굴 위치와 턱은 그림마다 직접 재 두었고(`js/heroes.js`의 `HEAD_AT`), 무기 자루처럼 머리에 닿은 가는 것은 떼어 내지 않습니다. 몸에 남는 긴 머리카락은 새 머리의 머리카락 색으로 칠합니다. 여성형 몸에는 여성형·중성 머리, 남성형 몸에는 남성형·중성 머리만 붙이고, 복면·투구는 전투 직업에만 씁니다. 수인은 늑대·여우 머리, 용인·리자드맨은 용 머리를 답니다.
- **같은 그림이라도 직업마다 다르게**: 직업마다 옷 색, 머리카락 색, 키를 다르게 칠합니다. 수식어가 붙은 직업은 그 수식어의 모습을 더합니다.
  - 종족: 엘프·고블린의 뾰족한 귀, 수인·고양이족의 동물 귀, 오크(초록 피부와 엄니), 트롤, 리자드맨, 언데드, 다크엘프의 피부색, 드워프·하플링·거인족의 체형
  - 혈통·신화급: 천사혈통·천상의 날개와 머리 고리, 악마혈통·마왕의 뿔과 박쥐 날개, 용혈의 용 날개와 뿔, 불사조의 불꽃 날개, 요정의 날개, 유령의 반투명한 몸
  - 그 밖: 쌍둥이의 분신, 그림자의 검은 잔상, 왕실·궁정·거장의 왕관, 속성(화염, 서리, 번개…)과 신화급 수식어(공허, 시공, 성좌…)의 기운
  - 등급: 영웅 이상은 등급 색으로 몸 둘레가 빛납니다.
- **전투 동작**: 걸어 다니지 않습니다. 만나면 두 받침이 양쪽에서 미끄러져 들어오고 그림자 같던 몬스터가 제 색을 찾습니다. 공격할 때 주인공은 한 걸음 나서며 무기를 들어 올렸다가(준비) 휘두르고(잔상), 근접 무기의 베기·찌르기·내려찍기는 몬스터 자리에서 터지고 활·총·마법은 주인공 손에서 몬스터로 날아갑니다. 맞은 쪽은 깜빡이고, 주인공은 움찔하며 붉게 번쩍입니다. 몬스터는 웅크렸다가 달려들거나 마력탄을 쏩니다. 이기면 승리 자세를 취합니다.
- **무기**: 직업마다 무기가 19가지 중 하나로 정해지고(그림과 직업 이름의 낱말로), 무기마다 동작·사거리·속도·피해가 다릅니다. 검(베기), 창(멀리 찌르며 둘을 꿰뚫음), 둔기(느리지만 내려찍어 셋을 함께, 땅이 울림), 쌍검(두 번), 주먹(짧고 빠름), 채찍(멀리 휘어 감음), 낫(앞뒤를 휩쓸음), 단검(빠르고 치명타), 활·석궁·총·포(포탄은 터지며 둘레까지), 지팡이(마력탄), 마도서(대상 자리에 룬이 터짐), 수정구(곧은 광선), 부적, 악기(음표), 소환수(혼령), 던지기(물약·카드·동전…).
- **기술 연출**: 기술 종류마다 다릅니다. 관통은 긴 찌르기나 광선, 연타는 무기 공격 세 번, 강타·기절은 내려찍기와 충격파, 화상·중독·저주·출혈은 불길·독 거품·보랏빛 연기·핏방울, 빙결은 얼음 분출, 흡수·마나는 대상에서 흘러 들어오는 빛, 혼란은 하트, 약화는 떨어지는 화살표, 강탈은 동전, 도박은 주사위, 급소·처형은 X자 베기입니다.
- **기술 그림**: 마력탄, 화염구, 얼음 분출, 번개, 운석, 운석 폭격, 룬 결정은 참고 시트(마법사의 밤)에서 오려 낸 그림(`assets/fx/`)을 속성 색으로 물들여 씁니다. 마법 궁극기는 마법진과 룬 결정 → 운석 폭격 → 빛기둥 순서입니다.
- **몬스터**: 61종. 도트 원본을 Scale2x/Scale3x로 키운 다음 실루엣에서 입체 음영과 색 외곽선을 자동으로 입힙니다.
- **배경**: 참고 게임(마법사의 밤)처럼 모든 지역이 달밤입니다. 밤하늘 세 단, 반짝이는 별, 픽셀 달과 달빛, 지그재그 산 두 겹(먼 산에 성 실루엣), 지평선 실루엣 줄(말뚝·전나무·묘비·첨탑), 위로 밝은 줄 두 개가 있는 보랏빛 땅과 점, 작은 마법 풀(몇 개는 빛남)을 코드로 그립니다. 지역마다 하늘·달·산·땅·풀 색이 다르고, 나무·바위·건물 같은 소품은 밤빛으로 덮고 등불·창문·문만 빛납니다.
- **계열 초상화**: 운명 뽑기 화면과 도감의 36개 계열 초상화(`assets/portraits/`)는 AI 이미지 생성으로 만들었습니다.
- **글꼴**: [갈무리11](https://github.com/quiple/galmuri) (SIL Open Font License 1.1, `assets/fonts/Galmuri-LICENSE.txt`). 한글·영문만 남기도록 줄인 파일입니다.

## 직업 구성

| 구분 | 내용 |
| --- | --- |
| 계열 | 36개: 전투 24개, 생활(비전투) 12개 |
| 기본 직업 | 731개, 모두 직접 작성한 이름·설명·대표 기술 |
| 수식어(기원) | 108개: 속성(화염, 심연…), 지역(북방, 사막…), 종족(엘프, 드워프…), 신분·성향(왕실, 타락한…), 신화급(용혈, 공허…) |
| 전체 직업 | 정확히 3,000개 = 기본 직업 731 + "수식어 + 기본 직업" 변종 2,269 |
| 등급 | 일반 1,200 · 고급 840 · 희귀 510 · 영웅 270 · 전설 135 · 신화 45 |

전투 계열: 전사, 기사, 궁수, 화약, 도적, 암살, 원소 마법, 비전 마법, 흑마법, 성직, 자연, 주술, 무도, 소환, 음악, 공학, 연금, 동방 무협, 사냥, 해양, 군사, 천체, 기예, 이형 혈통

생활 계열: 농업·목축, 채집·어업·광업, 제작·장인, 요리·식음, 상업·경제, 학문·지식, 예술·공연, 의료·돌봄, 행정·치안, 생활·서비스, 건축·토목, 신앙·신비

예: 광전사, 성기사, 흑기사, 검성, 북방 광전사, 타락한 성기사, 엘프 양봉가, 용혈 농부, 공허 제빵사, 드워프 대장장이, 유령 등대지기

생활 계열은 공격력이 낮은 대신 계열 특성이 강합니다. 농부는 매 턴 HP를 회복하고, 상인은 골드를 60% 더 벌고, 장인은 상점 물건을 싸게 사고, 학자는 경험치를 더 얻고 적의 약점을 꿰뚫어 봅니다.

각 직업은 기본 공격과 기술 5개를 가집니다: 계열 기술 2개, 대표 기술, 기원 기술(정통 직업은 대표 기술의 각성판), 궁극기(Lv.10).

```
└── tools/
    ├── verify-jobs.js    직업 수·이름 중복·데이터 값 검증
    ├── pack-heroes.py    assets/heroes/*.webp, assets/fx/*.png → js/data-heroes.js
    └── simulate.js       무작위 직업으로 쓰러질 때까지 전투를 돌려 계열·등급별 도달 층 비교
```

## 직업·밸런스 수정

- 기본 직업 추가: `js/data-jobs.js`의 해당 계열 `jobs`에 `이름|설명|대표 기술|기술 유형|주 능력치|등급|속성` 한 줄을 넣습니다. 총합은 생성기가 자동으로 3,000개에 맞춥니다.
- 수식어 추가: `js/data-world.js`의 `MODIFIERS`에 한 줄을 넣습니다.
- 캐릭터 그림 고르기: `js/heroes.js`의 `ART`에 `[그림 id, 계열 id, 직업 이름 낱말]`을 넣고 `assets/heroes/<그림 id>.webp`를 추가한 뒤 `python3 rpg/tools/pack-heroes.py`를 실행합니다. 생활 직업에 빌려 줄 그림은 `LEND`, 싸움 방식은 `STYLE_BY_PREFIX`·`STYLE_BY_ID`, 무기는 `WEAPONS`·`WEAPON_BY_ART`·`WEAPON_WORDS`, 수식어별 겉모습은 `MOD_LOOK`입니다. 새 그림의 머리를 바꿔 달려면 `HEAD_AT`에 얼굴 가운데 x, 턱 y, 얼굴 폭을 넣고 `HEAD_TAG`·`BODY_TAKES`에 종류를 적습니다.
- 몬스터 세기: `js/engine.js`의 `makeEnemy`, 한 층의 싸움 수는 `FIGHTS_PER_FLOOR`입니다.
- 수정 후 검증:

```bash
node rpg/tools/verify-jobs.js --sample        # 3,000개·중복 없음 확인, 표본 출력
node rpg/tools/simulate.js 600                # 무작위 직업 600명의 도달 층 (중앙값 약 57층)
```

진행 상황(캐릭터, 도감, 명예의 전당)은 브라우저 `localStorage`에 저장됩니다.
