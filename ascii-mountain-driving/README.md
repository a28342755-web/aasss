# ASCII MOUNTAIN DRIVING

아무도 없는 산악 오픈월드를 자동차 한 대로 달리는 ASCII 주행 게임입니다.
설치·빌드 없이 `index.html`을 브라우저에서 열면 바로 실행됩니다.

## 조작

| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 가속 · 조향 · 브레이크 (정지 후 계속 누르면 후진) |
| SPACE | 핸드브레이크 |
| Q / E, M | 기어 내림 / 올림, 자동·수동 변속 전환 |
| G | 차고 (정차 중): 차량 5종 · 타이어 4종 · 스프링 · 차고 높이 · 도색 · 주유 · 수리 |
| TAB / ESC | 월드: 날씨 · 계절 · 시간 · 저장/불러오기 · 새 월드 |
| C, H, R | 카메라(추적/원거리/보닛), 전조등, 마지막 안전 지점으로 복구 |
| [ ], T, P | 날씨 변경, 시간 배속, 일시정지 |
| F5 / F9, N, F1 | 저장 / 불러오기, 소리, 도움말 |

20초마다 자동 저장되며 다음 실행 때 이어집니다.

## 구조

| 파일 | 내용 |
|---|---|
| `js/world.js` | 시드 노이즈, 절차적 지형, 청크(근거리 2 m / 원거리 16 m 격자) 로딩, 도로·계류·폭포, 나무·바위 배치 |
| `js/env.js` | 시간, 계절, 날씨, 바람, 태양·달, 광원과 하늘색 |
| `js/car.js` | 차량 제원, 강체 물리, 서스펜션, 타이어, 엔진·변속기, 연료, 손상 |
| `js/render.js` | 글리프 아틀라스, 지형 레이마칭(조명·그림자·안개), 하늘 |
| `js/draw.js` | 나무·바위 스프라이트, 3D 차량, 파티클, 비·눈, HUD, 미니맵, 메뉴 |
| `js/audio.js` | Web Audio 절차적 사운드 |
| `js/main.js` | 입력, 카메라, 메뉴, 저장, 게임 루프 |

월드에는 경계가 없습니다. 플레이어 주변 청크만 생성하고 멀어진 청크는 버립니다.

## 검증

```
node test.js
```

지형 결정성, 도로 위 스폰, 5개 차량의 정지 자세·가속·변속·조향·제동·후진, 핸드브레이크 회전, 낙하 충격 손상을 확인합니다.
